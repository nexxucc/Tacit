Make project intent explicit.

Tacit turns a maintainer's spoken explanation into source-bound proposals. Clarify ambiguity, review evidence, and confirm a versioned snapshot that developers and coding agents can retrieve.

Development checkout for Arch Linux. The final development additions await testing. No public installer or validated release is available.

Install from your checkout

Install uv and Python, then clone the repository. Arch microphone capture and playback also require PortAudio and the audio extra.

cd Tacit
bash scripts/install-arch.sh --audio

The optional launcher is tacit-intent. Existing executables are never replaced. You can continue using uv run tacit inside the checkout.

Teach, clarify, confirm

  1. Sign in through the configured GitHub App. Your repository role controls teaching access.
  2. Capture speech with teach-voice and inspect the original transcript.
  3. Use teaching extract to propose grounded candidates through your configured Evon endpoint.
  4. Review alternatives and bounded scheduler scenarios with teaching review --ui.
  5. Resolve clarification, prepare a draft, and use confirm to publish its exact reviewed digest.

Model output stays a proposal until a human maintainer confirms it. Learners and delegated agents remain read-only.

Consume confirmed knowledge

uv run tacit context --repo REPO --snapshot SNAPSHOT --commit COMMIT
uv run tacit-mcp

Six local MCP tools return authorized text, evidence and snapshot identity. Exact retrieval uses no speech or reasoning provider. Optional cited text reasoning is explicit.

Run your backend

Configure PostgreSQL, GitHub and a stable encryption key. Provider keys stay on the backend. The API and worker are separate processes; migrations are explicit.

uv run --env-file .env alembic upgrade head
uv run --env-file .env tacit-api
uv run --env-file .env tacit-worker

See development.md and final-development.md in the checkout for commands, configuration and limits.
